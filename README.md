# Киржач Телеком — провайдер для AnyBalance

Провайдер для приложения [AnyBalance](https://play.google.com/store/apps/details?id=com.dukei.android.apps.anybalance) — показывает баланс и информацию по лицевому счёту интернет-провайдера **Киржач Телеком** (г. Киржач, Владимирская область) на экране телефона.

Данные берутся из личного кабинета: **https://lk.kirzhachtelecom.ru/login**

## Установка

1. Скачайте архив **`ab-internet-kirzach-telecom.zip`** из этого репозитория (кнопка **Code → Download ZIP** или со страницы релизов).
2. В приложении AnyBalance: **Меню → Провайдеры → Установить из файла** → выберите скачанный zip.
3. Создайте аккаунт, укажите **логин и пароль** от личного кабинета lk.kirzhachtelecom.ru.

> Провайдера пока нет в каталоге AnyBalance (https://anybalance.ru/catalog/): каталог наполняется из официального репозитория `dukei/any-balance-providers`, а туда провайдер ещё не добавлен (см. раздел «Публикация»).

## Счётчики

| Счётчик | Описание |
|---|---|
| Баланс | Текущий баланс. **При задолженности показывается со знаком минус** (услуга заблокирована за неуплату) |
| Стоимость в месяц | Сумма ежемесячной платы по тарифам |
| Рекомендуемый платёж | Рекомендуемая сумма к оплате (когда долга нет) |
| Сумма последнего платежа | Сумма последнего пополнения |
| Дата последнего платежа | Дата последнего пополнения |
| Вид последнего платежа | Способ оплаты (например, «Платежная система») |
| ФИО | ФИО абонента |
| Лицевой счёт | Номер лицевого счёта |
| Начало/Окончание расчётного периода | Даты расчётного периода (если указаны в ЛК) |

## Как это работает

Личный кабинет работает на биллинговой платформе **Hupo** (Ruby on Rails):
1. `GET /login` → извлекается CSRF-токен `authenticity_token`
2. `POST /login` с логином/паролем (с куками сессии)
3. Из HTML ответа извлекается JSON `new HupoApp({...})`, из которого берутся значения счётчиков

## Разработка

- **`provider/`** — файлы провайдера (манифест, `main.js`, библиотека, настройки, иконка, история версий)
- **`AGENTS.md`** — полная документация: как устроен провайдер, API AnyBalance, как тестировать и собирать архив
- **`test-harness.js`** — стенд для тестирования провайдера в Node.js без телефона:

```bash
KT_LOGIN=<логин> KT_PASS=<пароль> node test-harness.js
```

## Версии

## Публикация в каталоге AnyBalance

Чтобы провайдер появился в каталоге AnyBalance (https://anybalance.ru/catalog/), его нужно добавить в официальный репозиторий `dukei/any-balance-providers` (локально он склонирован в `../any-balance-providers`):

1. Сделать fork `dukei/any-balance-providers` в своём аккаунте GitHub.
2. Скопировать папку `provider/` в `providers/ab-internet-kirzach-telecom/` в форке.
3. Открыть Pull Request с изменениями.

После принятия PR провайдер появится в каталоге, и его можно будет устанавливать прямо из приложения AnyBalance.
